📖 How to Use Adopt(k)

🎯 What is Adopt(k)?

Adopt(k) is an AI-powered tool that automatically extracts key plan design information from 401(k) adoption agreements. Upload a PDF and get structured data in seconds — no manual data entry required.

🔒 Trust Contract: If Adopt(k) returns a value, it's certified correct. Empty fields mean we couldn't verify with 100% certainty.

📋 How to Extract Plan Data

  • Step 1: Select your preferred LLM model (Opus recommended)
  • Step 2: Click the upload area and select your adoption agreement PDF
  • Step 3: Click "Process Document" and wait for two-pass extraction (30–60 seconds)
  • Step 4: Review certified values and click "Source" to see evidence

✅ Understanding Status Badges

CERTIFIED
Value verified directly from document text.
AMBIGUOUS
Document uses unclear language.
CONFLICT
Multiple conflicting provisions found.
SILENT
Document doesn't address this provision.
💡 Pro Tip: Click the "Source" button on any certified field to see the exact document text that supports the extracted value.

✨ What's New in v3.0

🚀 Two-Pass Extraction

Adopt(k) now scans the entire document first to map which pages cover each topic, then extracts fields with targeted prompts. This dramatically improves coverage for contribution formulas, auto-enrollment details, and vesting schedules.

Result: Estimated 2x improvement in field coverage compared to single-pass extraction.
